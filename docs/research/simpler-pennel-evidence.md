# Evidence for a simpler Pennel

Reviewed 4 November 2026 for the user-approved Dictation/Meetings design. Official documentation is evidence of documented product behavior, not installed-app testing or measured usability. Pennel was inspected through current source and owned synthetic light/dark renders. Some competitor screenshot CDNs were inaccessible, so exact current competitor visual layouts were not verified.

## What the evidence supports

Wispr Flow describes a cursor, shortcut, speech, release and insertion loop, plus cancel and recovery paths. This supports keeping daily dictation inside the destination application and making Pennel's main Dictation surface preparation, recent results and recovery. Its account/cloud prerequisites do not fit Pennel's account-free local promise.

- https://docs.wisprflow.ai/articles/6409258247-flow-bubble-requirements
- https://docs.wisprflow.ai/articles/3152211871
- https://docs.wisprflow.ai/articles/9609615338-private-cloud-sync-and-data-sharing-preferences-in-wispr-flow

Granola documents a blank human note editor, optional transcript access, automatic enhancement after capture, provenance inspection and direct editing. Borrow the notes-first emphasis and one continuing meeting document. Do not copy implicit recording starts, calendar/account prerequisites or private-note use in shared outputs. Pennel's owner summary may use typed notes only with processing explained; a separate shareable summary uses transcript sources.

- https://docs.granola.ai/help-center/taking-notes/taking-notes-in-granola
- https://docs.granola.ai/help-center/taking-notes/ai-enhanced-notes
- https://docs.granola.ai/help-center/taking-notes/transcription

Superwhisper explicitly separates dictation History from Meetings, retains useful intermediate results for recovery, and distinguishes voice recognition from text formatting models. Borrow the two-job organization and stage-specific recovery. An on-device recognition model does not mean cleanup is also on-device; Pennel must explain both destinations.

- https://superwhisper.com/docs/get-started/history
- https://superwhisper.com/docs/get-started/choose-your-model
- https://superwhisper.com/docs/common-issues/llm-processing-error

Notion documents transcript citations with previews and passage jumps. Borrow nearby evidence access, with accurate source identity and return context. Calendar, workspace/database and automatic-sharing concepts are outside this effort.

- https://www.notion.com/help/ai-meeting-notes

## Pennel findings

The existing implementation already has task-first onboarding, atomic guided model choices, one main window and draft/session protections. The remaining burden is its meeting-centered persistent sidebar during Dictation, ten Settings categories with repeated Overview/Models summaries, and many formatting/people/speaker/AI choices around live capture. Reopening a meeting and explicit Review/export can use different surfaces. These are the implementation targets, not grounds to redo completed core safeguards.

## User decisions

Desktop first, iPhone later. Keep Glaze/Inter and native desktop chrome, with mobile branding preserved. Equal but separate Dictation and Meetings; History inside Dictation. Notes-first live meeting with closed-by-default companion. Automatic summaries offered explicitly, with a nonblocking choice on upgrade. Typed notes can guide owner summaries with the selected processing route disclosed; default sharing has a transcript-based preview excluding private notes.

## Validation still needed

Expected usability benefits are hypotheses. Human prototype feedback, two five-person formative rounds, actual receiving-app insertion, hardware capture/Stop latency, physical accessibility and installed-platform/iPhone keyboard acceptance remain open. No competitor study, participant outcome, real call or physical-device result is claimed by this research.
